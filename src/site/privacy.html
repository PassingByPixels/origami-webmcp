Privacy

This page says what happens to your data on origami.gratis. It is short because very little happens.

The site is static

Every page here is a file on a web host. There is no server that belongs to us, no account, no login and no database. We set no cookies. We run no analytics, no tracking pixels and no advertising code. We do not know that you came here.

Your documents stay with you

Each tool builds your document in the browser tab. You save it to a file on your disk, or the tool keeps a copy in your own browser's storage so that you can come back to it. Your document is never sent to us. There is nothing to upload, and no upload code in the page.

Agents

You can let an agent drive the tools on a page over WebMCP. That connection is between you and the agent host you chose. WebMCP runs inside your browser. We do not see the traffic, the prompts or the results.

Links out

The footer links to Buy Me a Coffee. That is a different company. After you click, their privacy policy applies, not this one. We load nothing from them: the link is plain text until you click it.
