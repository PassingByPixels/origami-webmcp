What is on the table

One file

Every tool here ends in one .origami.html file. Double-click it and it plays. The renderer is inside the file. There is nothing to install, and nothing to keep a subscription for.

Agents included

Every page hands its tools to an agent over WebMCP. A human can drive the same tools by hand, on the same page, in the same order. It works both ways: fold a deck yourself — here, or with the extension — then Open it on any tool page and hand the rest to an agent.

Connect your agent

To let an agent in this browser author a document, turn WebMCP on:

chrome://flags/#enable-webmcp-testing
— or launch Chrome with —
--enable-features=WebMCP

Then reload the page.

Private by construction

This is a static site. There are no accounts and no analytics. You make your document in the tab and you save it to your own disk, or to your browser's own storage. It is never uploaded.
